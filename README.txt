Voting System - TypeScript

Folder structure:

voting-system-typescript/
├── index.html
├── style.css
├── package.json
├── tsconfig.json
└── src/
    └── script.ts

Run:
1. Open this folder in VS Code.
2. Open the terminal.
3. Run: npm install
4. Run: npm run build
5. Use Live Server to open index.html.

The project uses TypeScript for the voting logic and DOM manipulation.
